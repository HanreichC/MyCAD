# Bedienung und Einstellungen

## Tastenkürzel

| Taste | Was |
|---|---|
| **Strg+K** | Befehlssuche: Befehle, Körper, Skizzen |
| **Strg+S** | Version sichern (mit Namen) |
| **Strg+Z** / **Strg+Umschalt+Z** | Rückgängig / Wiederherstellen |
| **Strg+N** / **Strg+O** | Neues Design / Öffnen |
| **S** | Skizze erstellen |
| **E** | Extrudieren |
| **F** | Abrunden |
| **H** | Bohrung |
| **Q** | Drücken/Ziehen |
| **M** | Verschieben |
| **J** | Gelenk |
| **Esc** | aktives Werkzeug weglegen, Notiz oder Scribble verlassen |
| **Entf** | Auswahl löschen |

Im Scribble:

| Taste | Was |
|---|---|
| **E** | Radierer an/aus |
| **V** | Auswählen |
| **L** | Senkrecht aufs Blatt sehen |
| **Tab** | Nur das Blatt |
| **Entf** | gewählte Striche löschen |

## Navigation

Zwölf Navigationsstile, z. B. **Fusion 360**, **SolidWorks**, **Blender**, **Siemens NX** und **Touchpad**. In den
Einstellungen zeigt MyCAD zu jedem Stil, welche Taste oder Geste dreht, schiebt, zoomt und wählt.

- Eine Taste als Maustaste, z. B. **Umschalt** als mittlere Taste – dann navigierst du mit dem Touchpad. Beim Tippen
  bleibt Umschalt Umschalt.
- MyCAD dreht um den Körper unter dem Mauszeiger.
- **Werkzeugnamen anzeigen** schreibt Namen unter die Symbole.
- Der **ViewCube** oben rechts dreht auf Standardansichten, das Haus darunter auf die Startansicht.

## Grafiktablett

Unter Wayland mit Druck und Schweben. Die Seitentasten drehen und schieben, auch während die Spitze aufliegt. In KDEs
Einstellungen **Zeichentablett** kannst du den Tasten des Tabletts Tasten zuweisen: **E** Radierer, **V** Auswählen,
**L** aufs Blatt sehen, **Strg+Z** Rückgängig.

## Einstellungen

Unten links **Einstellungen**:

**Allgemein**
- Erscheinungsbild Automatisch / Hell / Dunkel, **Liquid Glass** von Ultraklar bis Getönt
- Sprache Englisch / Deutsch
- Standard-Material für neue Körper
- **Materialien und Licht:** Realistische Materialien, Spiegelungen, Relief und Hirnholz, Kontaktschatten
- **Projektordner** (hier landen neue Designs)
- **Export-Auflösung** grob / normal / fein
- **Spiel beim 3D-Druck:** eng / normal / locker (Vorgaben für Passungen)
- **Überhang-Winkel** und **kleinste Wand** (Grenzen der Druckansicht)

**Navigation:** Navigationsstil, Empfindlichkeit

**Tasten:** Tasten als Maustasten, Belegungen

**Stift & Handschrift:** wie stark die Handschrift aufgeräumt wird (oder gar nicht)

## Materialien

**Darstellung** (Bereich WERKZEUGE) hat 119 Materialien: Metalle roh und poliert, eloxiertes Aluminium, Pulverlack und
Lacke, Kunststoffe matt bis glänzend, PLA mit Druckschichten, Gummi, Glas, Hölzer, Stein, Leder, Filz, Carbon. Viele sind
echte Fotoscans mit Relief; Holz zeigt Hirnholz an Schnittkanten.

- Kugel anklicken (wirkt auf gewählte Körper) oder auf einen Körper ziehen; mit einzelnen Flächen gewählt nur diese
  Flächen.
- Rechtsklick hält ein Material als Favorit, oben steht, was das Design schon benutzt.
- **Werkstoff** im selben Panel: die Dichte für **Messen** (Masse); folgt sonst der Darstellung.

## Dateien

- **Startseite** (unten links „Start“): zuletzt benutzt und Projektordner, mit Vorschaubildern und Suche.
- Rechtsklick auf den Designnamen oben im Browser: Version sichern, Speichern unter, Exportieren, **Varianten**,
  Umbenennen, Schließen, Löschen (in den Papierkorb).
- **Einfügen:** STEP (je Solid ein Körper), DXF und SVG in eine Skizze.
- Format `.mycad` (ZIP mit Vorschaubild, gleicher Inhalt wie `.FCStd`); `.FCStd` öffnet auch.
