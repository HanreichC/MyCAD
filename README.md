# MyCAD

Parametrisches CAD für Skizzen und Volumenkörper. Funktioniert wie Fusion 360, sieht aus wie eine Apple-App. Läuft nur unter Linux.
Basiert auf FreeCAD ([docs/UPSTREAM.md](docs/UPSTREAM.md)), Plan: [docs/PLAN.md](docs/PLAN.md).

```sh
./install.sh   # baut im Podman-Container (JOBS=6 Standard), legt Starter `mycad` + Menüeintrag an
mycad          # starten
```
